# 小账本 · 规格说明（Spec）

> **Spec 先行**：先写清楚"要做成什么样、怎么验收"，再动代码。
> 本文档既是开发依据，也是 PR 评审与 Demo 路演的对照清单。

| 项 | 内容 |
|---|---|
| 项目名 | 小账本（bookkeeping-assistant） |
| 一句话定位 | 用一句话记账，AI 帮你看懂钱包，再把省下的钱存进金库 |
| 方向 | 第 5 章方向 ③：其他工具/创意 —— 生活痛点（记账太麻烦） |
| 交付形态 | 一个开源仓库 = 可读的源码 + 点一下就能玩的作品 |
| 技术栈 | Python 3.12 + Flask + SQLite + 原生前端 + CNB LLM + Web Audio |
| 交付方式 | Docker 镜像 + CNB 仅预览模式一键启动 |

---

## 1. 背景与痛点

记账类 App 的留存杀手不是功能少，而是**录入成本高**：打开 App → 选收支类型 → 选分类 → 输金额 → 选日期 → 保存，六个动作才记一笔。绝大多数人坚持不过一周。

第二个痛点是**"记了也不会看"**：流水是一堆数字，看完不知道自己到底哪里该收手。

## 2. 目标与非目标

### 2.1 目标（必须做到）

| 编号 | 目标 | 验收方式 |
|---|---|---|
| G1 | 说一句话就能记账，且能自动识别金额、分类、日期 | 输入「昨天打车 32 块」→ 结果含 32 / 交通 / 昨天 |
| G2 | AI 识别结果**必须经用户确认**才入库 | 调用解析接口后流水数量不变 |
| G3 | 支持手动记账作为兜底 | 表单可提交并出现在流水中 |
| G4 | 能看到月度收支全貌 | 收入/支出/结余 + 分类占比 + 近 7 日趋势 |
| G5 | 能给出可读的消费洞察 | 返回一段中文结论，含最值得注意的点与建议 |
| G6 | **没有大模型也能完整使用** | 清空所有 LLM 环境变量后功能仍全部可用 |
| G7 | 一条命令即可运行 | `docker run` 后访问 8686 端口可见界面 |
| G8 | 云端零配置可用 AI | 容器内不填任何密钥即可调用大模型 |
| G9 | 可按需新建多个金库，往金库存钱并看到攒钱进度 | 新建 2 个金库，分别存钱，进度条与已存金额各自正确 |
| G10 | 存钱时有金币旋转坠落的动效，并伴随硬币入罐的音效 | 存钱成功后可见金币动画、可听到合成音效；静音开关可关闭音效 |
| G11 | 动效/音效不可用时不阻断存钱 | 禁用 Web Audio 或删除 `coin.js` 后，存钱仍成功且数据正确 |
| G12 | 能按日历回看每天花了多少 | 切换月份可见整月格子；有记录的日子按金额深浅着色；点某天展开当天流水 |
| G13 | 可自定义昵称、头像与背景 | 可选 emoji 或上传图片设头像；可选主题或上传图片设背景；刷新后仍然生效 |

### 2.2 非目标（明确不做，防止范围蔓延）

- ❌ 用户注册登录、多用户数据隔离
- ❌ 多账本、多币种、账户间转账
- ❌ 预算设置与超支提醒
- ❌ 账单导入/导出（CSV / Excel）
- ❌ 修改已录入的账单（只支持删除后重记）
- ❌ 移动端 App、微信小程序
- ❌ 自定义分类、年度报表、多轮 AI 对话

> 金库是**攒钱目标**，不是上述"多账本转账"或"预算提醒"：存钱不产生收支流水，也不会有超支告警。

## 4. 功能规格

### 4.1 F1 一句话记账

**输入**：任意中文口语账单描述，≤ 200 字。

**输出**：结构化账单预览（不入库）。

| 字段 | 规则 |
|---|---|
| 金额 amount | 必填（> 0），支持 `25元` / `32块` / `¥2000` / 裸数字 `88` / 小数 `13.5`；识别不到时返回 400 |
| 类型 type | `expense`（默认）或 `income`；命中收入词（工资/红包/收到/赚了…）判为收入，但**同一句里有"花钱买"语境时保持支出** |
| 分类 category | 支出 9 类 / 收入 7 类，未命中则 `其他` |
| 备注 note | 剔除金额与时间词后的片段，≤ 20 字 |
| 日期 happened_on | `今天/昨天/前天/大前天` 相对解析；`3月5日`、`3/5` 绝对解析；非法日期（如 2月30日）回退今天；无日期词默认今天 |
| 来源 source | `ai` 或 `rule`，前端据此展示解析来源标签 |

**异常处理**：任何情况下都必须返回可读的中文错误，不允许 500。

### 4.2 F2 确认入账

解析结果渲染为**可编辑表单**（类型/金额/分类/日期/备注均可改），用户点「确认入账」才写库。

- 分类下拉框与类型联动（切到"收入"换成收入分类）
- 服务端再次校验（不信任前端）

### 4.3 F3 手动记账

字段同 F2。默认展开状态为收起，点击「+ 手动记一笔」展开。

### 4.4 F4 账单流水

- 支持按 月份 / 分类 / 类型 过滤，可叠加
- 按 `happened_on DESC, id DESC` 排序
- 单条可删除，删除后流水与看板同步刷新
- 空状态给出引导文案

### 4.5 F5 月度看板

| 组件 | 内容 |
|---|---|
| 统计三格 | 收入 / 支出 / 结余（结余为负标红） |
| 分类占比 | 环形图 + 图例（分类名、金额、百分比），只统计支出，按金额倒序 |
| 近 7 日趋势 | 柱状图，固定 7 根柱（无支出补 0），右边界取 `min(月末, 今天)` |

### 4.6 F6 AI 消费洞察

- 输出一段 100~150 字中文：先概括收支 → 指出最值得注意的一点 → 给 1 条可执行建议
- 空账本返回引导语，不硬凑分析
- 模型不可用或调用失败时降级为规则模板，**接口仍返回 200**

### 4.7 F7 状态可见

顶栏角标显示当前模式：`AI 已就绪 · <模型名>` 或 `规则模式（未配置大模型）`。

### 4.8 F8 金库 · 攒钱罐

**输入**：金库名（必填，≤ 20 字）、目标金额（选填，0 表示不设目标）、图标（选填，默认 🏦）、备注（选填，≤ 50 字）。

| 能力 | 规则 |
|---|---|
| 多金库 | 按需新建任意数量，卡片网格自适应排列，新建的排在前面 |
| 已存金额 | `saved = SUM(vault_deposits.amount)`，不存冗余字段 |
| 攒钱进度 | `progress = saved / goal`；`goal = 0` 时恒为 0 且 **`achieved` 恒为 false** |
| 攒满判定 | `achieved = goal > 0 && saved >= goal`；进度不封顶，用于展示"超出目标多少" |
| 存钱 | 金额必填且 > 0，单次上限 1000 万；写入 `vault_deposits` 只增不改 |
| 删除 | 删除金库必须**连带删除**其存钱记录，不留孤儿数据 |
| 独立性 | 存钱**不产生** `records` 流水，**不影响**月度收支结余 |

**动效规格**（存钱成功后触发，顺序固定）：

| 阶段 | 内容 |
|---|---|
| ① 金币坠落 | 舞台内生成 3~10 枚金币（金额越大越多，上限 12）；`rotateY` 旋转 + 抛物线下落 + 缩小淡出 |
| ② 存钱罐弹跳 | 罐体 bounce 动画 500ms |
| ③ 飘字 | 罐体上方浮出 `+金额`，向上飘散淡出 |
| ④ 数字与进度 | 已存金额 700ms 缓动滚动到新值；进度条同步过渡；右上角总额刷新 |
| ⑤ 攒满庆祝 | 达成目标时额外播一段 C-E-G-C 上行琶音 |

**音效规格**：Web Audio 实时合成，**不引入任何音频文件**。单枚硬币由「叮（三角波金属共鸣）+ 当（带通白噪声）+ 咚（低频正弦）」三段叠加，音高带 ±15% 随机抖动；连续多枚最多播 6 声，避免糊成一团。

**降级与无障碍**：

- 提供音效开关（🔊/🔇），状态持久化到 `localStorage`，打开时试听一声；
- 系统 `prefers-reduced-motion: reduce` 时跳过位移动画，仅保留进度条联动；
- Web Audio 不可用或 `coin.js` 加载失败 → 静默降级为"只有动画"或"无动画"，**存钱始终成功**。

### 4.9 F9 日历视图

| 能力 | 规则 |
|---|---|
| 月份切换 | 上一月 / 下一月 / 回到今天；默认当月 |
| 覆盖范围 | 返回整月每一天，无记录的日子补 0；从周一开始排列 |
| 四种口径 | 支出 / 收入 / 收支 / 结余；切换只重绘格子，不重新请求 |
| 颜色深浅 | 按 `当天金额 / 当月单日峰值` 映射透明度，花得越多颜色越深 |
| 今日标记 | 今天带主色描边与圆点 |
| 当日明细 | 点某天展开当天流水与合计，可删除；再点一次收起 |

**配色规则**：支出暖橙、收入嫩绿、结余淡紫；无记录的日子统一浅灰底。

### 4.10 F10 个性化（头像 / 昵称 / 背景）

| 能力 | 规则 |
|---|---|
| 昵称 | ≤ 12 字，用于顶栏问候语与概览气泡 |
| 头像 | 内置 16 个 emoji 可选，也可上传图片；清空则回到默认 🐷 |
| 背景 | 6 套预设主题（奶油 / 薄荷 / 樱花 / 晴空 / 拿铁 / 薄暮），也可上传图片 |
| 图片处理 | 前端 canvas 压缩（头像 256px、背景 1600px）后再上传；后端只收图片 data URL 并限制体积 |
| 保存 | 面板内可实时预览，点「保存」才写库；偏好存在 `settings` 表，随数据库一起持久化 |

## 5. 数据规格

单表 `records`：

| 字段 | 类型 | 约束 |
|---|---|---|
| id | INTEGER | PK AUTOINCREMENT |
| type | TEXT | NOT NULL, CHECK ∈ {expense, income} |
| amount | REAL | NOT NULL, CHECK ≥ 0, 保留 2 位小数 |
| category | TEXT | NOT NULL |
| note | TEXT | NOT NULL DEFAULT ''，≤ 50 字 |
| happened_on | TEXT | NOT NULL，`YYYY-MM-DD`，建索引 |
| created_at | TEXT | NOT NULL，ISO8601 |

**分类枚举**

- 支出：餐饮 · 交通 · 购物 · 娱乐 · 居住 · 医疗 · 学习 · 人情 · 其他
- 收入：工资 · 奖金 · 兼职 · 红包 · 理财 · 报销 · 其他

**月份区间**：统一使用半开区间 `[本月 1 日, 下月 1 日)`，规避月末与跨年边界问题。

### 5.1 金库相关表

`vaults`：

| 字段 | 类型 | 约束 |
|---|---|---|
| id | INTEGER | PK AUTOINCREMENT |
| name | TEXT | NOT NULL，≤ 20 字 |
| icon | TEXT | NOT NULL DEFAULT '🏦' |
| goal | REAL | NOT NULL DEFAULT 0，CHECK ≥ 0，0 表示不设目标 |
| color | TEXT | NOT NULL DEFAULT '#ffa94d'，`#RRGGBB` |
| note | TEXT | NOT NULL DEFAULT ''，≤ 50 字 |
| created_at | TEXT | NOT NULL，ISO8601 |

`vault_deposits`：

| 字段 | 类型 | 约束 |
|---|---|---|
| id | INTEGER | PK AUTOINCREMENT |
| vault_id | INTEGER | NOT NULL，REFERENCES vaults(id)，建索引 |
| amount | REAL | NOT NULL，CHECK > 0，保留 2 位小数 |
| note | TEXT | NOT NULL DEFAULT ''，≤ 50 字 |
| created_at | TEXT | NOT NULL，ISO8601 |

**不变量**：`vaults.saved ≡ SUM(vault_deposits.amount WHERE vault_id = vaults.id)`。
由一条 `LEFT JOIN + GROUP BY` 单查询汇总（避免 N+1），不落冗余字段，因此永远自洽。

### 5.2 界面偏好表

`settings`（用键值对而不是宽表，以后加偏好项不用改表结构）：

| 字段 | 类型 | 约束 |
|---|---|---|
| key | TEXT | PK，取值 ∈ {nickname, avatar, bg_preset, bg_image} |
| value | TEXT | NOT NULL |
| updated_at | TEXT | NOT NULL，ISO8601 |

| 键 | 含义 | 约束 |
|---|---|---|
| nickname | 昵称 | ≤ 12 字 |
| avatar | 头像 | emoji（≤ 4 字符）或图片 data URL，≤ 400KB |
| bg_preset | 背景主题 | ∈ {cream, mint, sakura, sky, latte, dusk} |
| bg_image | 自定义背景图 | 空串表示用主题；非空必须是图片 data URL，≤ 1.5MB |

**不变量**：任一键缺失时由 `DEFAULT_SETTINGS` 补齐，接口永远返回完整结构，前端不必判空。

## 6. 接口规格

详见 README 的「API 文档」章节。约定：

- 全部返回 `application/json; charset=utf-8`
- 错误统一 `{"error": "<中文提示>"}`
- 成功 `200`，新建 `201`

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 健康检查 + AI 可用性 |
| POST | `/api/parse` | 一句话 → 结构化账单（不落库） |
| POST | `/api/records` | 新增账单 |
| GET | `/api/records` | 流水查询（`month` / `date` / `category` / `type`） |
| DELETE | `/api/records/{id}` | 删除账单 |
| GET | `/api/summary` | 月度统计 |
| GET | `/api/calendar` | 按月返回逐日收支（日历数据源） |
| GET | `/api/settings` | 读取界面偏好 |
| PUT | `/api/settings` | 更新界面偏好（部分更新） |
| POST | `/api/insight` | 生成消费洞察 |
| GET | `/api/vaults` | 金库列表（含已存金额 / 次数 / 进度） |
| POST | `/api/vaults` | 新建金库（201） |
| DELETE | `/api/vaults/{id}` | 删除金库及其存钱记录 |
| POST | `/api/vaults/{id}/deposit` | 存钱入库（201） |
| GET | `/api/vaults/{id}/deposits` | 某个金库的存钱流水 |

错误码：

- 金库接口：`400` 名称为空/超长、目标为负、非数字、存入金额 ≤ 0；`404` 金库不存在；
- 日历接口：`400` `month` 不是 `YYYY-MM`；
- 流水接口：`400` `date` 不是 `YYYY-MM-DD`；
- 个性化接口：`400` 背景主题不存在、图片格式不支持或超出体积上限。

## 7. 非功能规格

| 维度 | 要求 |
|---|---|
| 可用性 | 无大模型环境下功能完整；无网络环境下界面正常渲染 |
| 可移植性 | 一条 `docker run` 可运行；不依赖外部数据库/缓存/CDN |
| 数据安全 | 数据仅存本地 SQLite；密钥只走环境变量，`.env` 不入库 |
| 可维护性 | 分层单向依赖；解析器为纯函数；分类枚举单一来源集中定义 |
| 性能 | 单月统计一次 SQL + 一次遍历；日历按月一条 GROUP BY；金库列表一条 JOIN 聚合（无 N+1）；前端零第三方依赖 |
| 可测试性 | 单测不依赖网络与凭证，可离线跑绿 |
| 安全 | 参数化 SQL 防注入；前端输出转义防 XSS；个性化接口只收图片 data URL；容器非 root 运行 |
| 资源体积 | 动效与音效**零素材文件**（CSS 动画 + Web Audio 合成）；用户上传的图片先压缩再入库，仓库与数据库都不会被大图撑爆 |

## 8. 验收清单

**功能**

- [ ] 「昨天打车 32 块」解析出 支出 / 32 / 交通 / 昨天
- [ ] 「今天发工资 12000」解析出 收入 / 12000 / 工资
- [ ] 「买了本理财书 50 元」判为**支出·学习**（不被"理财"带偏成收入）
- [ ] 解析后不点确认，流水不增加
- [ ] 手动记账可提交
- [ ] 流水可按月/分类/类型过滤，可删除
- [ ] 看板三格数字与流水一致，环形图占比合计 100%
- [ ] 近 7 日柱状图固定 7 根
- [ ] 洞察返回中文结论；空账本返回引导语

**金库**

- [ ] 能新建多个金库，卡片按网格排列，新建的排在前面
- [ ] 分别往不同金库存钱，各自已存金额与进度互不串味
- [ ] 存钱后金币旋转坠落 + 飘字 + 数字滚动 + 进度条同步变化
- [ ] 存钱时能听到硬币入罐音效；点 🔊 关闭后不再出声，刷新页面开关状态保持
- [ ] 设了目标的金库攒满后卡片进入 achieved 态并播庆祝音；未设目标的进度条不冒充满格
- [ ] 删除金库后，其存钱记录一并消失
- [ ] 存钱**不会**改变月度收入/支出/结余，也不会出现在流水里

**日历**

- [ ] 日历显示整月，月首正确对齐到周一
- [ ] 闰年 2 月显示 29 天，跨年切换月份不漏数据
- [ ] 切换 支出/收入/收支/结余，格子里的数字与底色随之变化
- [ ] 花得最多的那天颜色最深，无记录的日子为浅灰底
- [ ] 今天有描边标记；点某天展开当天流水，再点收起
- [ ] 在日历里删除某笔后，格子金额与月度看板同步更新

**个性化**

- [ ] 选 emoji 换头像，顶栏与页头同步变化；刷新后保持
- [ ] 上传图片换头像，图片被压缩后入库
- [ ] 切换 6 套背景主题，页面背景即时预览；刷新后保持
- [ ] 上传背景图后，预设主题变暗（图片优先）；点「恢复主题背景」可回到主题

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| AI 解析错误污染账本 | 解析与入库分离 + 用户确认 + 服务端二次校验 |
| 无大模型时功能残缺 | 规则通道降级（正则 + 关键词表）；洞察模板降级 |
| 关键词误判（"买理财书"） | 泛化动词不参与分类判定，仅作支出语境线索 |
| 评审环境无外网 | 零 CDN、零构建产物、零外部字体 |
| 跨年统计漏数据 | 月份统一用半开区间 |
| `onlyPreview` 锁死开发环境 | 预留 dev 分支专用配置 |
| Fork 后一键启动失败 | `launch` 镜像地址写常量；端口四处对齐 |
| 金库存钱被重复计入结余 | 金库独立成表，不写 `records`；用例锁死该行为 |
| 动效/音效拖累甚至阻断存钱 | 动画状态只由接口响应驱动；降级为空函数；`maxDuration` 内不阻塞 |
| 用户上传大图撑爆数据库 | 前端 canvas 压缩到指定长边后再上传；后端再按格式与体积双重校验，超限直接 400 |
| 日历排版边界出错（闰年 2 月 / 跨年） | 日历由后端逐日聚合、周一对齐；用例逐月核对天数 |
| 自定义背景图导致文字可读性下降 | 卡片始终为近白半透明底；背景仅作用于页面底层，不参与文字层 |
| 浏览器自动播放策略导致没声音 | 首次点击预热 `AudioContext`；`resume()` 兜底；提供显式开关并试听 |
| 仓库被二进制素材撑大 | 金币用 CSS 动画、音效用 Web Audio 合成，零 `.png` / `.mp3` |
